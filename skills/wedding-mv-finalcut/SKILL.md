# 婚礼预告 / MV / 全程：Final Cut 原素材剪辑

交付按本次时长和叙事要求完成、能继续修剪和恢复原声的 Final Cut 工程。使用当前环境允许的应用控制或 FCPXML 工作流；没有应用控制能力时，先完成可导入工程，并明确尚未完成的应用内验证。

## 开始前确定范围

- 读取当次要求、素材目录或用户选材时间线、参考视频 / 音乐、目标工程和指定结尾。缺少会影响制作的必需信息才询问。
- “只用现有时间线上的素材”限定到**已有片段的源文件及已选源区间**。可以排序、裁短、变速；不能自行从素材库加片，也不能向片段前后扩展。增加外部镜头或新的源区间需要用户明确授权。
- 用户允许重新选材时，按授权范围检查素材；不要沿用另一个项目的选材限制。保留不同人物和关系的辨识度，避免只剩相似的唯美肖像。
- 区分预告 / MV 与婚礼全程。全程的按时间顺序、有效内容覆盖规则不能套在短片上；收到全程任务时，读取 [全程覆盖规范](references/full-wedding.md)，不执行短片的精选删减。

## 按本次模式读取规则

- 预告通常 30～60 秒，以当次指定时长为准；MV／微电影通常 3～6 分钟，可自定义。结构、节奏与内容侧重分别决定编排，不只换名称。
- 所有模式先读 [稳定核心与重复取舍](references/shot-selection.md)。全程再读 [全程覆盖与事件防漏](references/full-wedding.md)。
- 需要誓言旁白时读 [语句、说话人与画面匹配](references/vows-and-semantic-editing.md)；没有人声要求时不强行加入誓言。
- 这些是 Agent 剪辑工作规则，不意味着安装后就具备本地视频识别、声纹模型或自动成片程序。实际依赖取决于执行环境。

## 保护用户版本

重剪前备份当前时间线，优先导出含原始媒体引用的 FCPXML；在同一资源库另建清晰命名的重剪项目。以用户最新手工调整和最终成片为当前依据，不能把助手初稿覆盖到用户最终版本。若当次明确要求修改原工程，也先备份。

先核对工程实际内容，不依据旧截图判断它仍为空或仍是助手版本。应用被锁定或用户正在操作时，停止冲突操作，继续可独立进行的分析；不要把尚未执行的导入报告为完成。

## 选镜与节奏

先看参考片，再听指定音乐的段落、落点、起伏和尾奏。按当次目标建立镜头表，记录原片、源入点 / 出点、时间线位置、时长、速度及内容。**没有固定的33秒或40秒模板，也没有能适配所有音乐的固定剪切点。**

本节描述短片；全程以完整有效内容覆盖为先。观看候选片段及准备采用的段落，掐掉起步晃动、找机位、构图调整、失焦、穿帮和无意义准备收尾。缩略图 / 联系表用于定位，不代替对有效动作、入点和出点的播放检查。避免反复使用同一段画面；同一原片的不同段落只有在内容确实不同、叙事有用且授权允许时再用。

用场布全景、细节和运镜交代空间，配合新人摆拍，以及适量伴郎伴娘、亲友互动、牵手、亲吻或礼花等真实情绪。让空镜在音乐呼吸处发挥作用，不为凑切点机械加镜头。关灯后的舞台 / 场布、剪影可能是有效空镜；检查实际内容，不能仅因画面暗就当成缺失媒体删除。

结尾严格服从当次指定的合影、人物动作或空镜。指定某组 / 全场合影时，确认人物与组合正确，相邻编号的另一组照片不能替代。

仅在需要叙事或风格示例时阅读 [references/story-and-style.md](references/story-and-style.md)。

## 保持原素材可编辑

- 时间线直接引用原始源文件，保留原文件名或用户既有命名；不要把先渲染的短段或一段成片当作主剪辑素材导回工程。
- 原声组件保留。音乐主导时可静音 / 降至静音电平，用户仍能恢复；不要先转成无声视频来“省事”。
- 使用用户指定参考音乐。抽取参考片音频只用于用户当前剪辑，不能作为本 skill 的公开资产分发。
- 慢动作匹配实际素材帧率和动作。优先使用足够的真实采样帧；低帧率过度慢放、光流造成脸、手、头纱畸变时，减轻变速或换稳定段落。
- 较长的场布运镜可使用平滑加速，但保留有效构图与运镜核心。变速留在工程中，避免以中间视频烧死。
- 排版克制，优先原生字幕或用户提供的排版素材。核对文字、帧率、可用模板及水印；不要擅自编造新人姓名、日期或加入商业模板演示水印。小画面拼贴只在适合参考风格和人物内容时使用。
- 调色以当前场地、肤色、婚纱与参考风格为依据。先核对 Rec.709 / Log 等素材状态，不能把其他婚礼的蓝金或黑金处理强加到本场。

通过 FCPXML 组织或检查工程时，阅读 [references/fcpxml-native-editing.md](references/fcpxml-native-editing.md)。

## 验收与交付

先做文件和时序检查，再在 Final Cut 中核对实际导入结果。验证项目名、画面 / 字幕 / 工程帧率、总长、每处接点、音乐起止、缺失媒体、意外空隙、尾部黑帧、变速及指定结尾。修正帧边界警告；不要仅因 XML 语法通过就宣布完成。

核对原片引用及已有选材范围；用回导 XML 比较预定镜头与实际时间线。可用 `scripts/audit_fcpxml.py` 辅助检查简单时间线：

```bash
python3 scripts/audit_fcpxml.py after.fcpxmld --expected-duration 40 --selection before.fcpxmld
```

其中 `40` 是示例，应替换成本次要求。脚本不分析画面、音乐节拍、原声恢复操作或复杂效果；报告需要人工复核的结构 / 平滑变速时继续人工核验，不能把报告当作成片验收。

播放并检查 Final Cut 实际导出。应用导出的成片与离线参考预览分开标明；离线近似变速预览不能冒充应用内实际导出。使用当前环境允许的控制工具，不绕过权限，也不强行干扰用户操作。

用户要求加快时，集中完成一版后一次导入和必要核验，避免没有新变化的反复导入、渲染或重新测试。最后打开正确的重剪项目，说明时长、选材重点、结尾、可编辑状态和任何未完成验证，提供可用的预览 / 工程路径。

## 初稿与正式复核

用户要先去 Final Cut 检查时，可交付明确标记“初稿待复核”的可编辑 XML，不要求先在外部软件逐条勾选。保留真实核对状态；不替用户批量声明已看过。初稿仍检查媒体存在、授权范围、时序和音轨，不以“初稿”为理由忽略硬错误。正式交付再完成实际运动、原声、事件和全部未用片段的复核。

未选择配乐时确认是否跳过：全程可保留原声继续；预告／MV 可先检查素材，音乐驱动的编排仍须获得音乐，除非本次明确要求无配乐。
